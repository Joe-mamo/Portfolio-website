# Portfolio Website

Personal engineering portfolio website for Joseph Lilly.

## Why I Built This Site

I built this website as a way to showcase both my engineering projects and how I use AI as a tool. Almost the entire site was created with the help of AI, but it took a lot of prompting, testing, adjusting, and problem-solving to get it where I wanted it. I wanted to show that I can take an idea, communicate what I want clearly, work through problems when the result is not right, and use AI to turn that idea into something functional and polished.

AI is becoming more common in engineering, school, and everyday work, so I thought building my portfolio this way would be a good way to demonstrate how I can use it effectively instead of just saying that I know how to use AI. The projects and experiences throughout the website are my own; AI was the tool I used to help design and build the site around them.
